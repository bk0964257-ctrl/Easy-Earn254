# EasyEarn254

Flutter app project for a Kenya-focused earning and rewards platform.

## Current foundation
- Home dashboard
- Balance card
- Tasks section
- Wallet section
- Profile section
- Bottom navigation
- Material 3 interface

## Run
1. Install Flutter.
2. Open this folder in Android Studio or VS Code.
3. Run `flutter pub get`.
4. Run `flutter run`.

The next development stage is to add real account authentication, a database, task management, earnings ledger, M-Pesa payout integration, and an admin panel.
